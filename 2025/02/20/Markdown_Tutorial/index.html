Markdown Tutorial

发表于 2025-02-20 更新于 2025-04-02 Valine：

Markdown 是一种轻量级的 标记语言，由 John Gruber 和 Aaron Swartz 于2004年共同设计。它通过简单的纯文本语法实现文档内容的格式化，目标是让用户专注于内容本身而非排版细节，同时保持文档的易读性和易写性。

核心特点

  1. 轻量简洁 语法简单直观，仅需少量符号即可完成排版。
  2. 跨平台兼容 纯文本格式可在任何设备上打开，支持转换为 HTML、PDF、Word 等格式。
  3. 应用场景广泛 GitHub、API文档、团队文档、博客、笔记、论文、邮件、社交平台。

写作规范

参考 google style guide、latex 规范、Markdown规范。

  • 段首无缩进，段与段之间两个换行。
  • 英文/公式/引用/代码块与中文之间一个空格，与中文标点之间无空格。
  • 所有数学符号均使用 LaTeX，其他英语名词不使用LaTeX。
  • 列表嵌套使用 tab 分层，列表标题如果是单词/短语不加句号。
  • 长公式尽量写在行间公式。
