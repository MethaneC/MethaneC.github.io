Python Introduction

发表于 2025-02-05 Valine：

Python introduction 简要记录。oop 部分先搁置。

运算符
  • 算数运算符：+-*/% ** //
  • 比较运算符：== != > < >= <=
  • 赋值运算符：= += -= *= /= **= //=
  • 逻辑运算符：and or not
  • 成员运算符：in/not in 对象是否存在于某个集合中（字符串，列表，元组）
  • 身份运算符：is/is not 比较内存位置是否相同
  • 位运算符：& | ^ ~
流程语句
  • 判断语句： if/elif/else
  • 循环语句： for in/else while/else continue break
  • 异常： try/except as/else/finally raise
  • module： import from as
  • switch： match/case
  • 文件： with as
  • 其他： pass del assert
类型
  • 数字：int/float/complex
  • 字符串： str str[] str.find() str.maketrans() str.replace() str.split() str.join() len(str) format% f-string
  • 列表：list list[] list.append() list.insert() list.pop() list.copy() list.count() list.clear() list.extend() list.remove() list.sort() list.reverse() len(list)
  • 元组：tuple tuple[] len(tuple)
  • 字典：dict dict.clear() dict.fromkeys() dict.pop() dict.update() dict.copy() dict.keys() dict.items() len(dict)
  • 集合：set set.add() set.copy() set.clear() set.remove()

注：常量的赋值是深拷贝，其他的复制时浅拷贝（使用 obj.copy() 深拷贝）

函数
  • 自定义函数： def fun(arg,arg=, *arg,arg,**arg) ，arg= 有默认值， *arg 接受剩余参数，*arg/* 后的arg 接受关键字参数， **arg 接受所有关键字参数。 *arg 是 tuple ， **arg 是 dict ，反过来同理。
  • 内置函数： input() print() abs() max() min() id() hash() eval() exec() enumerate() repr() type() locals() gobals() zip()
  • 高阶函数： filter()/map()/reduce()/sorted()
  • 有关类的函数： isinstance() type() dir() getattr() hasattr() setattr() delattr()
  • 匿名函数： lambda return : expression
  • 闭包： nonlocal global
feature
  • 切片： slice(begin,end,step) [begin:end:step]
  • 生成器：yield()/next(generator) StopIteration
  • 迭代器：class.__iter__()/class.__next__() （iterator/generator/str/list/tuple/dict/set 可迭代）
  • range： range(begin,end,step) （是一种迭代器，左闭右开）
  • 列表推导式： [expression for iterator in obj if condition]
  • 装饰器： @decorator
object
  • 继承： class A(B,C)
  • 私有变量/函数： __name
  • 函数：def fun(self, args) ，其中 self 相当于 this
  • 专有函数： __init__ __new__ __del__
  • 运算符重载： __repr__ __setitem__ __getitem__ __le__ __ge__ __eq__ __ne__ __add__ __sub__ __mul__ __truediv__ __mod__ __pow__ __call__
  • 内置函数重载： __str__ __hash__ __len__ __iter__ __next__ __getattr__
  • 专有属性：__class__ __name__ __dict__ __base__ __doc__ __slots__
  • @property @name.setter
