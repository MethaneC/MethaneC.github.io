Docker 使用
docker 的几个概念
  • image ：程序的安装包
  • container ：运行的程序
  • docker file ：安装包的构造文件
  • docker-compose ：多个 container 项目的配置文件
  • network ： container 之间连接网络
  • volume ： container 之间和外部的文件存储
